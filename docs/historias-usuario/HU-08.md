# HU-08 — Visualización de emergencias

**Código y título:** HU-08 — Visualización de emergencias  
**Como:** Responsable de emergencias  
**Quiero:** consultar el estado y los datos de las emergencias registradas  
**Para:** conocer la situación documentada en SafeRoute.  
**Actor:** Responsable de emergencias. **Prioridad:** Alta (propuesta).

## Validación INVEST

Independiente: Sí. Negociable: Sí, filtros no especificados. Valiosa: Sí. Estimable: Sí, tras definir campos visibles. Pequeña: Sí. Comprobable: Parcialmente.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Consulta de emergencias
  Escenario: Hay emergencias registradas
    Dado que SafeRoute contiene emergencias
    Cuando el Responsable abre la vista de emergencias
    Entonces puede consultar sus datos y estado registrados
  Escenario: No hay emergencias
    Dado que SafeRoute no contiene emergencias
    Cuando el Responsable abre la vista de emergencias
    Entonces SafeRoute presenta un estado vacío informativo
```

## Supuestos y reglas de negocio

- El diagrama de contexto devuelve estado de emergencia y la vista de desarrollo contiene PanelResponsable. No se presume notificación en tiempo real.
