# HU-15 — Visualización de rutas

**Código y título:** HU-15 — Visualización de rutas  
**Como:** Usuario evacuado  
**Quiero:** visualizar la ruta calculada en un plano de la infraestructura  
**Para:** comprender la secuencia espacial indicada por SafeRoute.  
**Actor:** Usuario evacuado. **Prioridad:** Alta (propuesta).

## Validación INVEST

Independiente: No, requiere una ruta calculada. Negociable: Sí. Valiosa: Sí. Estimable: Parcialmente, la representación y metadatos espaciales requieren definición. Pequeña: Sí. Comprobable: Parcialmente.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Visualización de ruta
  Escenario: Mostrar ruta calculada
    Dado que SafeRoute calculó una ruta válida
    Cuando el evacuado abre el resultado
    Entonces el plano resalta los espacios y conexiones que componen esa ruta
  Escenario: No hay ruta calculada
    Dado que aún no se calculó una ruta
    Cuando el evacuado abre la vista de ruta
    Entonces SafeRoute indica que primero debe solicitar una ruta
```

## Supuestos y reglas de negocio

- El plano es una representación ilustrativa de infraestructura registrada; no un mapa GPS ni una visualización de personas.

**RF:** RF-19. **Componentes:** Cálculo y visualización de rutas; RutaDTO, PantallaEvacuacion. **Mockup:** M15 `../mockups/html/15-resultado-ruta.html`.
