# HU-03 — Gestión de edificios, pisos y espacios

**Código y título:** HU-03 — Gestión de edificios, pisos y espacios  
**Como:** Administrador  
**Quiero:** registrar y mantener la institución, sus edificios, pisos y espacios  
**Para:** disponer de la infraestructura que utilizará el sistema de evacuación.  
**Actor:** Administrador. **Prioridad:** Alta (propuesta).

## Validación INVEST

Independiente: Sí. Negociable: Sí, atributos y validaciones requieren RF completos. Valiosa: Sí, es base del grafo de espacios. Estimable: Parcialmente. Pequeña: No, agrupa entidades relacionadas; se conserva la agrupación solicitada. Comprobable: Parcialmente.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Administración de infraestructura
  Escenario: Registrar una jerarquía de infraestructura

  Escenario: Consultar jerarquía registrada
    Dado que existe infraestructura registrada

```
