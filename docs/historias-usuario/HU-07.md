# HU-07 — Identificación de zonas afectadas

**Código y título:** HU-07 — Identificación de zonas afectadas  
**Como:** Responsable de emergencias  
**Quiero:** asociar espacios afectados a una emergencia  
**Para:** identificar las zonas que deben considerarse durante la evacuación.  
**Actor:** Responsable de emergencias. **Prioridad:** Alta (propuesta).

## Validación INVEST

Independiente: Sí, requiere una emergencia registrada. Negociable: Sí. Valiosa: Sí. Estimable: Parcialmente. Pequeña: Sí. Comprobable: Parcialmente.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Zonas afectadas
  Escenario: Asociar un espacio afectado
    Dado que hay una emergencia registrada y el espacio existe
    Cuando el Responsable lo identifica como zona afectada
    Entonces SafeRoute lo asocia a la emergencia y muestra la asociación
  Escenario: Selección de espacio inexistente
    Dado que el espacio indicado no pertenece a la infraestructura registrada
    Cuando el Responsable intenta asociarlo
    Entonces SafeRoute informa el problema y no guarda la asociación
```

## Supuestos y reglas de negocio

- El dominio muestra ZonaAfectada asociada a Emergencia y Espacio. Si “afectada” equivale a “bloqueada” y cómo se propaga a conexiones se debe precisar.

**RF:** RF-10. **Componentes:** Gestión de emergencias; EmergenciaService y entidades Emergencia, ZonaAfectada, Espacio. **Mockup:** M07 `../mockups/html/07-zonas.html`.
