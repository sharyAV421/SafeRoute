# HU-14 — Cálculo de rutas de evacuación

**Código y título:** HU-14 — Cálculo de rutas de evacuación  
**Como:** Usuario evacuado  
**Quiero:** solicitar una ruta desde el espacio seleccionado  
**Para:** conocer una opción de evacuación hacia un destino disponible.  
**Actor:** Usuario evacuado. **Prioridad:** Alta (propuesta).

## Validación INVEST

Independiente: No, requiere infraestructura, estado de emergencia, origen y destinos. Negociable: Sí. Valiosa: Sí. Estimable: Parcialmente; algoritmo y desempates pendientes. Pequeña: No, RF-17 y RF-18 se agrupan según la solicitud. Comprobable: Parcialmente.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Solicitud de ruta de evacuación
  Escenario: Existe recorrido disponible
    Dado que el origen y la infraestructura necesarios están registrados
    Y existe un destino de evacuación alcanzable
    Cuando el evacuado solicita una ruta
    Entonces SafeRoute devuelve un recorrido formado por espacios y conexiones disponibles
  Escenario: Un bloqueo impide un recorrido
    Dado que hay espacios o conexiones identificados como bloqueados
    Cuando SafeRoute calcula la ruta
    Entonces no incluye los elementos bloqueados en el recorrido
  Escenario: No existe recorrido disponible
    Dado que ningún destino es alcanzable desde el origen con los elementos disponibles
    Cuando el evacuado solicita una ruta
    Entonces SafeRoute informa que no se encontró ruta
```

## Supuestos y reglas de negocio

- La exclusión de espacios y conexiones bloqueados está declarada en la solicitud; el UML representa estados de espacio, conexión y ruta. La semántica del bloqueo debe confirmarse.
- El algoritmo, selección entre múltiples rutas, unidades de distancia y modelo de tiempo estimado no están definidos en los diagramas. Son decisiones pendientes y no se fijan aquí.

**RF:** RF-17, RF-18. **Componentes:** RutaController → RutaService → RutaRepository; servicios de infraestructura, emergencia y riesgos; entidades RutaEvacuacion, PasosRuta. **Mockup:** M14 `../mockups/html/14-calculo-ruta.html`.
