# HU-09 — Configuración de niveles de riesgo

**Código y título:** HU-09 — Configuración de niveles de riesgo  
**Como:** Administrador  
**Quiero:** consultar y configurar niveles de riesgo disponibles  
**Para:** que la gestión de riesgos use el catálogo acordado.  
**Actor:** Administrador. **Prioridad:** Media (propuesta).

## Validación INVEST

Independiente: Sí. Negociable: Sí. Valiosa: Sí. Estimable: Parcialmente, faltan rangos y permisos de modificación. Pequeña: Sí. Comprobable: Parcialmente.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Niveles de riesgo
  Escenario: Consultar niveles disponibles
    Dado que existe el catálogo de niveles del sistema
    Cuando el Administrador consulta la configuración
    Entonces SafeRoute presenta los niveles definidos
  Escenario: Configuración inválida
    Dado que el Administrador envía una configuración que no cumple las reglas acordadas
    Cuando intenta guardarla
    Entonces SafeRoute informa los campos que requieren corrección
```

## Supuestos y reglas de negocio

- El UML enumera NivelRiesgo (BAJO, MEDIO, ALTO, CRITICO). No define umbrales, si el catálogo es editable ni quién puede cambiarlo; la interfaz los marca como pendientes.

**RF:** RF-12. **Componentes:** Gestión de riesgos; RiesgoController/Service y enum NivelRiesgo. **Mockup:** M09 `../mockups/html/09-configuracion-riesgo.html`.
