# HU-12 — Visualización de riesgos y prioridades

**Código y título:** HU-12 — Visualización de riesgos y prioridades  
**Como:** Responsable de emergencias  
**Quiero:** visualizar los riesgos y prioridades asociados a espacios  
**Para:** consultar la información de riesgo disponible durante la gestión de la emergencia.  
**Actor:** Responsable de emergencias. **Prioridad:** Alta (propuesta).

## Validación INVEST

Independiente: Sí como consulta; depende de datos existentes. Negociable: Sí. Valiosa: Sí. Estimable: Parcialmente. Pequeña: Sí. Comprobable: Parcialmente.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Consulta visual de riesgos
  Escenario: Riesgos disponibles
    Dado que existen características de riesgo o prioridades registradas
    Cuando el Responsable consulta el plano o listado de riesgos
    Entonces SafeRoute muestra su asociación con los espacios correspondientes
  Escenario: Sin datos de riesgo
    Dado que no hay riesgos registrados para la selección consultada
    Cuando el Responsable abre la vista de riesgos
    Entonces SafeRoute informa que no hay datos disponibles
```

## Supuestos y reglas de negocio

- La vista de contexto indica que el responsable consulta mapa, riesgos y prioridades. La representación visual es ilustrativa y no representa ubicación de personas.

**RF:** RF-15. **Componentes:** Gestión de riesgos; RiesgoController/Service, PanelResponsable y entidades de riesgo. **Mockup:** M12 `../mockups/html/12-mapa-riesgos.html`.
