# HU-13 — Selección de ubicación del evacuado

**Código y título:** HU-13 — Selección de ubicación del evacuado  
**Como:** Usuario evacuado  
**Quiero:** seleccionar manualmente mi edificio, piso y espacio de origen  
**Para:** solicitar orientación desde la ubicación que indiqué.  
**Actor:** Usuario evacuado. **Prioridad:** Alta (propuesta).

## Validación INVEST

Independiente: Sí, antecede a la solicitud de ruta. Negociable: Sí. Valiosa: Sí. Estimable: Sí. Pequeña: Sí. Comprobable: Sí, una vez definidos los selectores y validaciones.

## Criterios de aceptación (Gherkin)

```gherkin
Característica: Selección manual del origen
  Escenario: Seleccionar espacio existente
    Dado que la infraestructura está registrada
    Cuando el evacuado selecciona manualmente edificio, piso y espacio
    Entonces SafeRoute conserva ese espacio como origen de la solicitud
  Escenario: No se selecciona un espacio
    Dado que el evacuado no ha seleccionado un espacio de origen
    Cuando intenta solicitar una ruta
    Entonces SafeRoute solicita completar la selección
```

## Supuestos y reglas de negocio

- La selección manual está explícita en el diagrama de contexto. No se usa GPS, geolocalización, rastreo ni inferencia automática de ubicación.

**RF:** RF-16. **Componentes:** Cálculo y visualización de rutas; PantallaEvacuacion y cliente API; InfraestructuraService para consultar espacios. **Mockup:** M13 `../mockups/html/13-ubicacion.html`.
